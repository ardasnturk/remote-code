## Remote Code 1.4.1

### Fixed

* **Updates install again.** Installing an update from the Mac app stopped with
  "The update's code signature is invalid", although the update was signed and
  notarized correctly: the disk image's window design marked the app in a way
  the strict signature check rejects. The disk image no longer does, and the
  updater ignores that marker. From 1.3.0 or 1.4.0, **Install and Relaunch**
  now works.

Includes everything from [1.4.0](https://github.com/ardasnturk/remote-code/releases/tag/v1.4.0).
