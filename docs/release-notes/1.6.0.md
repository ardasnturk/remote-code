## Remote Code 1.6.0

**Plugins.** A tool on your Mac can now be a tab on your phone, and Vitrin is the first.

**Vitrin on your phone** needs Remote Code 1.6.0 on the Mac and Vitrin 2.1.0. If Vitrin isn't on the Mac yet, Settings → Plugins installs it.

* Add your app folders from the phone with the file browser.
* Work on a project in native screens: setup, research, metadata, screens, design, video, review, upload and Claude.
* Projects you add on the phone or on the Mac show up on the other right away.
* Run App Store Connect from the tab: apps, versions, TestFlight, reviews, prices, analytics, users, signing and every asc command.
* Connect with an API key or your Apple Account, and create new apps.

The Vitrin Mac app doesn't need to be open. Remote Code starts what it needs.
