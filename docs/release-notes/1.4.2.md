## Remote Code 1.4.2

### Fixed

* **Updates no longer hang at "Installing…".** After downloading and checking
  an update, Remote Code waits for its chats to stop before it quits — and that
  wait could block itself, so the app never quit and the update never
  finished. From 1.4.2 on, **Install and Relaunch** quits, installs and reopens
  the app within seconds.

**Updating from 1.4.1 or earlier:** the old version still has the problem, so
this one update may stay at "Installing…". Force quit Remote Code (⌥⌘⎋ or
Activity Monitor) within two minutes; the update then finishes and the new
version opens by itself. Or install the DMG below, or run
`brew upgrade --cask remote-code`.
