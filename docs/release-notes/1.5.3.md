## Remote Code 1.5.3 (iOS)

Promo Studio from the phone, with Promo Studio 1.6.0 on the Mac:

* **Make it later** for a new video or image: pick a time, and whether the
  storyboard is approved and the result posted automatically.
* Planned posts have their own section. Until their time, change the request,
  time and options, start them now or delete them.
* "Post at" is translated.

With an older Promo Studio the option doesn't appear, since it would start
the post right away. The Mac app is unchanged; it stays at 1.5.1.
